# Бункер — игра для компании с телефонов

Каждый заходит со своего телефона по коду комнаты или QR. Ведущий запускает игру,
всем раздаются карты, дальше раскрытие, голосование и изгнание прямо в приложении.

## Деплой на Vercel

1. Залей содержимое этой папки в новый репозиторий на GitHub
   (index.html, package.json, папки api и lib).
2. Vercel → Add New → Project → выбери репозиторий → Deploy. Настройки не трогай.
3. В проекте открой Storage → создай базу Upstash Redis (бесплатный план) и подключи её к проекту.
4. Deployments → у последнего деплоя ⋯ → Redeploy. Без этого шага база не подцепится.

Через терминал вместо GitHub: `npx vercel` в этой папке, потом шаг 3, потом `npx vercel --prod`.

## Как играть

- Ведущий жмёт «Создать комнату» и показывает QR или код.
- Карты открываются кнопкой «Открыть» — их сразу видят все во вкладке «Игроки».
- Голосование запускает ведущий, итоги видны после закрытия, изгоняет тоже ведущий.
- Спецкарты: игрок нажимает «Сыграть», ведущий выполняет действие во вкладке «Ведущий».
- Если телефон перезагрузился или открылся другой браузер — вход с тем же именем и PIN с карты.

Свои профессии, фобии, катастрофы и спецкарты можно дописать в `lib/data.js`.
