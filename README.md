# Бункер — made by WeAreAble

Игра для компании: каждый заходит со своего телефона по коду комнаты или QR.

## Файлы
- `index.html` — весь интерфейс.
- `api/game.js` — сервер: комнаты, раздача, голосование, финал.
- `lib/data.js` — все колоды. Сюда можно дописывать свои карты.

## Как устроен баланс
У каждой карты есть очки от −3 до 3. При раздаче игра подбирает руку так,
чтобы сумма у всех была примерно одинаковой:
- сильной профессии (хирург, военный) обязательно достаётся заметная слабость;
- слабой профессии (таролог, SMM «Пятёрочки») — козырь в багаже, хобби или факте;
- пол делится поровну, в компании всегда есть пара, способная продолжить род;
- реально полезных профессий примерно треть, остальные — угар.

В финале игра проверяет медицину, еду, технику, защиту, здоровье группы,
климат в коллективе и продолжение рода с учётом катастрофы и выносит вердикт.

## Как добавить карту
Строка в `lib/data.js`: `очки теги | текст`, например
`2 med | Умеет вправлять вывихи`. Подробности в комментарии в начале файла.

## Деплой
Vercel + Upstash Redis (Storage → Connect). После изменений в GitHub Vercel
пересобирает сайт сам.
